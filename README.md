# site-responsivo-com-anuncios

Site responsivo para celular com layout moderno, área de promoções, painel de configuração de anúncio e popup recorrente.

## Como abrir

1. Acesse a pasta do projeto.
2. Abra `index.html` no navegador.
3. Ou rode um servidor local, por exemplo:

```bash
python3 -m http.server 8000
```

Depois abra `http://localhost:8000`.

## Funcionalidades

- layout mobile-first
- hero com CTA e cards
- painel para editar texto, intervalo e cor do anúncio
- banner fixo no rodapé
- popup de anúncio que reaparece automaticamente
- botão flutuante de promoções

## Personalização

Edite os campos do formulário na página ou altere os valores padrão diretamente em `script.js`.
